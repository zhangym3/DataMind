# Insight Agent 剩余功能与验收边界

更新日期：2026-10-30；版本：`1.0.0-rc1` 源码。本轮未重新打包，`dist` 的旧验收不代表新增回填能力已完成目标机验收。

这份清单描述当前代码的真实状态。它不再把工程描述成 UI 演示：核心链路已经接入本地持久化、文件解析、受控 LangGraph、精确计算、在线模型适配和导出。仍然需要把代码证据与外部环境、真实业务数据和真实供应商验收分开看。

## 已实现并有自动化证据

- Python 3.11 x64、PySide6/QWebEngine 桌面 UI、独立工作进程和 SQLite/WAL 持久化。
- 文件选择、拖放和 Ctrl+V 文件导入；纯文本 Ctrl+V 仍进入输入框。原件使用 CAS 托管、哈希去重并保存导入状态。
- `.xlsx/.xls/.docx/.doc` 解析和内容画像；`.doc` 由内置 `doc2txt`/Antiword 及 `olefile` 回退解析为文本。文件用途识别为数据、指标说明、混合、未知或其他，混合和未知不会绕过能力校验进入计算。
- 当前对话一份指标说明，自动解析、证据定位、全文校验、不可变快照与绑定；独立目录解析支持分批保存和继续。指标管理已恢复，支持版本发布、克隆、比较、默认与停用，以及无需在线模型的手工新增和编辑。
- `document-fill/1.1` 原文位置计划、八字段模型意图、失败批次拆分、有限语义纠正和累计预算；本地取数后逐位置回填，完整保留正文及缺口。
- 字段映射、关系版本、覆盖和冲突检查；类型安全规则 DSL、受控算子、`Fraction` 精确计算、行级审计、跳过记录和离线冻结重算。
- 固定 LangGraph 流程 `prepare -> compute -> audit -> commit`，有 SQLite checkpoint、队列、租约、fencing、幂等提交、取消、恢复和安全退出。
- 在线模型配置和三种协议适配：OpenAI Responses、OpenAI Chat Completions 兼容接口、Anthropic Messages。Key 通过 Windows Credential Manager 保存，数据库、日志、检查点和备份不保存 Key。
- 出站字段白名单和脱敏、调用账本、请求预算、能力检查；模型只做提取/规划/解释，不执行代码、不计算正式数字。
- 本地准备查询（帮助、查看附件/数据/口径/设置）、结果筛选/排序/分页、公式查看、指定运行引用、意图和历史上下文清单。
- 会话分页、搜索、重命名、归档/恢复、复制、反馈、重新生成入口、比较/趋势、DOCX/XLSX/CSV/JSON/分析包导出、备份恢复、诊断和报告内容校验。
- 四个固定可信 SkillAdapter，输出 Schema 校验和 runtime manifest；附件路由是固定编排子图，不允许附件动态安装 Skill 或脚本。

最新指标管理验收：全量 285 个测试通过；手工维护与本地计算界面 40 项、原有工作台界面 32 项、开始分析自动准备及续算 21 项检查通过，详见 [指标管理恢复记录](metric-management-restoration-2026-10-30.md)。早期取数回填验收中 `document-fill-pytest.xml` 记录 225 个测试通过，回填、失败提示、独立目录界面共 31 项检查通过；Deepseek 真实重放完成 47 处登记与诊断报告，但为 0 处可信数值、47 处缺口，详见 [取数回填验收记录](acceptance-document-fill-2026-10-30.md)。Windows 韧性、30 万行容量、冻结版及 ZIP 的既有验证属于原打包版本的历史证据。

## 明确未实现或暂不承诺

- Windows 7、完全离线大模型、多用户/登录/组织权限、多租户服务。
- PDF 输入、图片/OCR、压缩包、远程 URL/共享盘和任意附件动态扩展。
- Word 超长内容的自动分块合并；超过文档节点/大小上限会要求拆分或失败关闭。
- `first_event`、`sequence_classify`、`snapshot_as_of` 准备算子，领域 manifest 中 capability 仍为 `false`。
- 回填路径中首台、连台、延误/停台比率、时点接台、平均最晚及计划快照的复杂明细计算；日期/科室/时间文字自动填充。可用的严格结构化汇总可取值，其余保留具体缺口。
- 任意指标的医学解释或自动猜测缺失口径；零基期、不可比窗口和缺失点不会伪造数值。
- 像素级 Office 版面保证、签名安装器、自动更新和在线服务端 API。HTTP 路径只作为未来契约映射，当前产品是本地桌面服务。
