# Insight Agent 1.0.0-rc1 操作手册

适用 Windows 10/11 x64。首次运行无需配置模型即可打开应用；在线提取、自然语言意图、AI_REQUIRED 复核及解释需要有效模型 Key。明确参数的本地分析和已冻结合同重算可不调用在线模型。

## 1. 配置模型

进入设置的“模型服务”页，可新建多套连接配置。每套配置独立保存服务商、HTTPS Base URL、协议、模型 ID、调用参数和 Key；在左侧选择配置即可编辑，勾选启用及默认后供新的分析使用。服务商预设提供地址，不自动选择账号可用的模型 ID。自定义服务必须兼容已支持的三种协议之一。

点击“立即测试连接”会同步发送固定 JSON 样例并在设置页直接返回结果，不进入后台处理，也不会阻塞导入或分析。未保存的表单可以直接测试；已保存配置留空 API Key 会复用凭据管理器中的 Key。测试不会清空输入框或删除已保存 Key。通过仅代表鉴权、连通及最小 JSON 响应通过；提取长文档和业务复核还需实际验证。401/403 请核对 Key/权限，429 请稍后重试，协议错误核对模型名称、地址和协议。应用不静默跟随跳转，不自动切换其他服务商。使用系统证书校验；首版不提供代理及自定义 CA 设置。

同一服务更新配置且 Key 留空会保留已有 Key。改变服务商、地址或协议会移除旧凭据并要求重新填写。删除 Key 后配置仍保留，可重新填写；删除配置会移除对应 Key。Key 只在原生窗口输入，不回填到网页。

最大输出 Token 可设到 1M（1,000,000），累计 Token 预算默认也是 1M，可在“分析与界面”页调整。实际请求会受模型接口能力及扣除输入预留后的剩余预算约束；官方 DeepSeek Flash/V4 Chat 接口的单次上限为 393216。配置额度表示允许生成的上限，不会要求模型必须生成这么多内容。已冻结任务沿用原预算，更新配置后须建立新的解析代次或运行。

## 2. 导入与用途确认

在新建会话中选择多个文件、将文件拖入窗口，或在对话输入区按 Ctrl+V 粘贴资源管理器中复制的文件。复制普通文字则在输入框插入文字。一次复制多文件遵守批次限制；重复内容使用哈希去重。原件会复制到本机工作区。

文件按实际格式及结构识别为数据文件、指标说明、混合、未知或其他内容。典型历史报告归为“其他文件”并排除；出现规则与历史结果冲突时保留未知。识别采用本地保守规则，不保证覆盖所有文档表达；未知内容须人工核对用途，混合内容须拆分，不能强制指定为单一用途。格式不兼容时即使人工指定用途也不能强制参与计算。Excel 形式的指标说明请另存 DOCX，Word 明细表请另存 XLSX。用途变更保留识别证据及历史记录。

点击附件查看结构、Sheet/行数和用途；可打开托管原件。准备阶段可移除附件，已锁定会话需点击“新建数据对话”后重新导入说明文档和数据文件。不会因源文件后来修改而改变冻结副本。

## 3. 解析当前对话的指标说明

只上传 Word 时自动解析说明内容，可点击右侧“解析指标说明”查看进度，或在对话输入“解析指标说明”。无需上传 Excel。解析先整理目录，再分批补充每项的单位、维度、统计期间、公式、条件、排除、待确认项和原文依据。可展开每项的原文证据核对；“解析完成”表示说明内容已整理，存在待确认项的指标仍需补充口径。

处理中可查看已保存目录和进度；失败后检查错误及模型设置，点击“继续解析”接着整理未完成项。相同原文和解析版本下，已完成批次会保留。此功能使用设置中的在线模型，解析目录本身不锁定会话，也不改变已有计算规则。

当前对话同时有 Word 指标说明和 Excel 时，系统自动准备计算规则或模板待填计划，校验原文证据及全文覆盖后用于本次计算。后来补传或确认 Excel 用途也会触发准备。右侧“说明文档中的指标”可查看计算条件、无法计算的原因以及原文。需要跨对话复用或手工维护口径时，可使用左侧“指标管理”。

说明中需要明确统计实体、日期归属、阈值、单位、字段以及缺失、非法、重复数据和空集的处理政策。语义不明确的指标会跳过并说明原因，不推测业务政策。请完善原说明文档，在准备阶段先移除当前说明再上传新文档；移除或更换说明会清除旧规则与映射。

目录按原文分段整理，明细按指标分批补充；超时或输出截断时会自动缩小批次并保留已完成项。单项仍失败时可点击“继续解析”或“重试解析”，也可重复上传同一文件；系统会重新排队未完成解析，不会把旧失败当作新任务结果。有效规则在内部生成不可变快照用于追溯，用户无需维护规则 JSON 或执行发布步骤。

含 `X台`、`X人` 等占位的说明会建立原文待填位置计划，数字、日期和文字分别登记，右侧显示待填位置数。登记完成表示位置和含义已核对，不表示数据已满足计算条件。日期和科室/时间文字当前保留待补充提示，不自动使用系统昨日。点击“开始分析”会在需要时准备当前说明的指标规则，复用正在进行的解析，成功后自动继续本次分析，无需再次点击。若本次准备失败，会显示对应错误；处理错误后可重新开始分析或手动重试解析。

### 指标管理与手工新增

进入左侧“指标管理”，主列表逐项展示指标名称、统计口径、统计方法、单位、所属版本和状态。默认汇总每个指标集最新创建的未删除版本，包含草稿；维护旧版本不会让旧版变成最新版。新版本尚未解析时不会回退显示旧指标。停用状态保留展示，停用版本不能新绑定对话。

使用“指标版本”下拉框可单独查看任一历史版本，搜索框按当前版本搜索全部指标的名称、口径或方法；每页 25 项，可翻页查看。点击“查看指标”可核对完整口径、待补原因、原文及规则证据，再点击“编辑指标”。手工指标使用统计表单，普通 Word 指标可维护名称、说明、执行状态与规则，原文待填项使用专用取数计划表单。取数方式仍须符合原文要求；修改原文要求时请更新 Word 后重新上传。相同名称但原文位置不同的指标分别展示，不按名称合并；“分析时核验”表示已登记取数方案，是否可取得数值仍需结合材料核验，“待补充”会保留原因。

批量删除仅针对指标：勾选指标行或“全选本页指标”，点击“批量删除指标”，核对名称、填写维护人并输入“确认删除”。翻页和搜索保留已选项，切换版本或取消选择会清空选择；支持同一次删除多个指标集中的指标。取消确认不改数据，任一指标版本已变化、正在解析或选择失效时，整批操作失败并回滚，请刷新后重新选择。详情内也可单独删除指标。

草稿中的修改和删除直接保存。编辑或删除已发布指标时，成功保存才自动创建同系列的新草稿，原发布版与已有对话、历史运行不变；指定版本筛选会跟随新草稿。核对并发布后，新建对话或准备中的对话可选择新版本；已有对话不会自动切换。删除记录随发布快照及分析合同保存，字段映射和新分析跳过已删除指标。为保留说明原文的逐位置对账，原文证据仍保留，回填报告的对应位置显示“指标已删除，不参与计算”。全部指标删除后不能发布空版本，历史版本筛选仍可查看旧指标。

导入 Word 说明、手工新增、发布、修改及删除后，主列表自动更新。原文、版本说明、复核发布、创建新版本和历史维护位于下方可展开的“版本与说明管理”。库中导入的文件在指标管理中处理，不会创建新对话或混入当前对话。对话内上传的私有说明仍在所属对话维护，不自动进入共享指标库。

导入后，下方“导入与解析进度”自动展开，更新每份文件的读取、解析和用途识别记录。生成草稿后，继续显示原文节点数、整理出的待填位置、当前批次大小与原文位置、已保存的指标名称、已完成数量、证据与全文覆盖校验、耗时以及最终结果。“查看与维护”弹窗也显示同一份实时进度，不覆盖正在填写的版本说明。等待模型响应时显示等待提示，数量只在真实批次保存后更新；数字待填项的识别百分比不代表整体解析已经完成，仍需通过后续校验并保存草稿。普通规则文档在模型返回前显示等待状态，不估算指标数。

失败时显示对应文件或当前解析的错误代码、原因和最后已完成数量；可在进度卡片点击“重试解析”。原文与已成功保存批次保留，重试进展按新的处理记录展示。重新打开页面仍可查看已记录进度和结果；解析完成后点击“查看与复核解析结果”核对并发布。此处完成表示解析完成，业务口径仍需人工复核。

手工新增步骤：

1. 填写指标集名称、指标名称、统计口径、维护人，选择领域、统计对象、统计方法和单位。
2. 指定日期字段标识；去重计数另填唯一编号字段，求和、均值、最小/最大值另填数值字段。字段标识使用英文字母、数字和下划线，以字母开头；实际 Excel 中文列名通过后续字段映射对应。日期映射采用 ISO 日期，例如 `2026-10-01`。
3. 可添加一个文本或数值比较条件。条件记录占比必须填写分子条件，分母是窗口内全部记录；选择百分比时乘以 100。缺失或非法值使该指标跳过；计数空集为 0，数值聚合空集和比例分母为 0 时跳过。日期范围左闭右开、时区为上海。
4. 点击“校验并保存”创建草稿。在详情中可继续新增或编辑手工指标。表单直接生成受控规则及不可变人工口径证据，无需 Word、模型 Key 或在线解析。
5. 核对口径和证据，点击“复核并发布”，填写复核人并勾选确认。发布后的快照保持不变；直接编辑或删除指标会在成功保存时自动创建新草稿，也可先点击“创建新版本”继续维护。旧版本和历史结果继续保留。
6. 点击“新建对话使用”，导入 Excel、确认字段映射后“开始分析”。也可在准备中的对话右侧选择已发布指标版本，或从管理详情点击“用于当前对话”。切换版本会清空旧映射，需重新核对；已锁定对话不能切换版本。

手工表单支持记录数、唯一编号去重计数、求和、平均值、最小值、最大值和条件记录占比。同一指标集只使用一个领域。默认版本在选择窗口中预选，新建空白对话不自动绑定。停用版本不能新绑定，原会话与冻结运行仍保留；停用不可撤回，需要维护时创建新版本。

Word 草稿可在线提取、添加人工补充及通过高级结构化规则维护。原文全文覆盖未检查完时，需先完成提取和复核；已检查的普通规则草稿可以追加手工指标。含原文待填位置的回填计划使用专用流程，不接受追加手工计算指标，请另建指标集。重新提取会替换草稿候选，界面会先提示确认。删除记录不会因重新提取而消失；普通规则重新生成了指标标识、无法保留已删除项的原文引用时，将拒绝替换并保留当前草稿，需上传新版本说明重新建立指标。高级修改过的手工规则不再使用旧表单回填，避免旧口径覆盖新规则。

版本详情中的“删除指标说明”需输入“确认删除”，支持草稿和已发布版本，仅提供逐份删除。删除后该说明版本及其指标列表不再出现在指标管理中；已有会话、运行或其他版本引用时，系统保留原文与指标快照供历史追溯。已删除快照不能新绑定、继续编辑、发布或重新解析；已有引用仍可查阅，也可重新上传说明建立新草稿。正在提取时需先等待完成或取消任务；已发布版本也可选择“停用”以保留管理列表记录。

## 4. 映射、计划和分析

默认按本次上传的全部记录计算说明中的指标。同名标准字段自动匹配，多个符合字段要求的工作表按同一实体合并，仍校验实体键、重复记录和数据有效性。这里的全量只表示本次输入范围，不代表某个月份或期间的数据完整性。

字段不一致时打开“字段映射”，确认来源表和字段含义。基础表单适用于单表，多表 union 和 join 可使用高级配置，明确关联键、基数及范围依据。手动保存的映射优先，未映射的指标会列出原因。

关联支持 1:1、1:n、n:1，含糊多对多和冲突会拒绝。日期窗口左闭右开，例如 2026-10-01 至 2026-11-01 覆盖十月。完整性声明不能由文件中最早/最晚日期替代。

点击“开始分析”或在输入框描述计算目标，默认使用当前全部数据；有完整期间依据时也可明确统计窗口，Agent 会按请求生成元数据计划或真实分析。第一次有效计划/分析会冻结口径、文件、映射和基线；无效参数/帮助不会锁定。重复提交使用幂等请求。之后可在同一数据范围内更换合法窗口重新分析；更改附件或映射须新建会话。

用户以对话方式提交请求，文件解析、模型调用、比较和导出在后台自动处理；当前对话和附件区域直接显示处理中及最终结果。运行预算/内存超限不会发布半成品。应用重启后会按原预算、租约和版本检查恢复未完成处理；版本不一致需保留旧记录并新建运行，不能静默继续旧检查点。

## 5. 查验结果与追问

结果只从已提交运行读取。查看每项原文证据、字段/Sheet 来源、精确分子分母、输入/纳入/排除计数和跳过原因。含待填位置的说明按原文顺序回填数值或【待补充：具体原因】，保留全部规则和公式。全部缺口显示“待补充资料”，可导出含完整正文及缺口清单的诊断报告；技术失败单独显示，不能当作有效报告。

取数会检查本次全部材料，但不会把退单、首台子集和全明细直接相加。简单数量及时差人数需要明确实体键、日期和实际事件依据；已有结构化汇总还需指标、单位、日期、维度及完整口径一致。当前首台、连台、计划快照等复杂明细算子尚未完成，不满足条件的位置会保留原因。

追问/解释/重新生成必须引用明确运行；不自动猜“上次”指哪个结果。数字沿用本地计算，模型解释不得引入新数字。可复制回答、反馈或撤销反馈。会话支持搜索、分页、重命名、归档及恢复。

“离线冻结重算”复用原合同并检查结果摘要一致，不连接模型；原政策要求 AI 复核时，仅允许复用合同和结果均一致的既有通过记录。图/技能/规则版本不同会拒绝。

同比、环比或趋势先分别完成相同冻结基线上的窗口分析，再选运行比较。不同单位/粒度/政策/数据基线不可直接比较；零基期、缺组和跳过点明确标记。图表使用显示值，精确值见表格和 JSON。

## 6. 导出和报告核验

- DOCX：只读取已提交且通过核验的结果；含待填位置的说明使用原文内容骨架回填，并附缺口清单。内容校验后可另存；缺少渲染器仍为版面未核验草稿。
- PDF：仅在 LibreOffice 可用时启用，同时关联源 DOCX。生成成功仍需逐页查看预览，确认中文字体、表格、分页及页眉页脚，填写检查人后才能标记版面通过。
- XLSX/CSV/JSON：保存指标、单位、窗口、精确值及分子分母；回填运行同时保留正文和缺口。CSV 包含防公式注入处理。
- 分析 ZIP：包含汇总、处理清单、审计、合同摘要及文件哈希，不含原始数据文件或模型 Key。分析包不是可恢复备份。
- 诊断：仅用于技术排查，含版本、状态、错误码、阶段耗时和请求标识哈希，不含业务正文或原件。

报告使用受信生成器，可修改标题；指标说明只作为正文和待填位置依据，不作为可执行模板。`.doc` 导入使用内置 Python 文本解析器，不依赖 LibreOffice；旧格式只提供文本证据，不保证页面布局、图片文字、修订或嵌入对象。PDF 页面渲染仍需 LibreOffice，缺少渲染器时只禁用 PDF 并保留未核验 DOCX 草稿；不通过 Office COM 自动修改原件。

## 7. 备份、恢复、迁移与删除

当前处理完成后，在设置的维护页创建加密备份到工作区之外。备份含原件及业务历史，采用加密 7z、密码至少 12 字符，密码不会保存在应用中。备份不含 Key，恢复后须重新配置。

恢复必须选择新的空目录，先校验归档、文件哈希、数据库及引用完整性，再切换到恢复目录并重启。不得覆盖现用工作区。目录迁移复制并校验数据，保留原目录供回退，按界面提示重新启动。

归档仅隐藏会话，不删除数据。永久删除操作需显式确认且不能删除正在处理的会话依赖；清理先展示无引用文件预览。保留期设置不自动销毁数据，实际删除需人工确认。
