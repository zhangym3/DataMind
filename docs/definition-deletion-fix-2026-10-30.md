# 指标说明草稿删除修复（2026-10-30）

当共享说明草稿被另一个已发布版本的 `parentId` 引用时，旧逻辑返回 `DEFINITION_REFERENCED`，导致用户无法从指标管理中删除草稿。

## 删除行为

- 无引用草稿仍删除定义、派生指标目录及无其他使用方的源附件记录，保留删除审计。
- 有会话、运行、映射、版本或其他持久化历史引用时，记录 `deletedAt`，从指标管理和版本选择列表中移除；保留原文、附件及指标快照供历史追溯。已发布子版本的内容、清单哈希及绑定保持不变。
- 已删除快照不能编辑、复制、发布、重新提取或作为新版本的父版本。重新导入同一 Word 会跳过已删除快照，建立可见草稿；历史附件不会重新显示为待确认文件。
- 保留“确认删除”、revision 和活动任务校验。已发布版本仍使用停用。

界面确认框解释历史保留行为，删除成功后显示“草稿已删除，已引用的快照保留用于历史追溯”。删除标记使用现有 JSON 对象存储，无需变更数据库结构。
