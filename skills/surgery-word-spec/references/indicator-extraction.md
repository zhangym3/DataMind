# 指标说明提取与取数检查表

这是一份审阅清单，不能替代运行提示和真实原文，也不能把本案例的指标硬编码成所有文档的解析结果。

## 先确认目标

整批上传识别后，没有 Excel 的对话自动解析指标目录与口径；同时或之后加入 Excel 再准备计算合同。重复上传失败的说明会复用定义并重新排队；仅复用完整结果和活动任务。目录每批登记最多12个原文节点，全文只作上下文，返回名称、简短类别和定位；不在类别中堆放规则或未决事项。目录完成后，明细每批最多四项。超时或截断逐级二分，每个成功子批立即保存，重试只处理未覆盖节点和未完成明细。模型请求的单次时间限制和任务总预算仍然有效。

检查回执中的实际输出量及推理令牌，不能把输出额度全部被推理消耗误判为文档太大。对网关明确支持的官方 DeepSeek Flash/V4 提取请求显式关闭思考；其他协议或兼容服务保留各自能力边界。

用户只要解析指标说明时走独立 catalog：目录及规则整理，不需要 Excel。用户点击分析时，含占位符说明走报告回填：按文档要求从全部材料取数或本地计算，最后回到原文位置；目录提取完成不是分析完成。

## 文档完整性

- 依照章节、日期、指标、维度行和文末规则建立关联，不丢跨节点阈值和例外。
- 分别检查原文节点覆盖和待填位置覆盖，不能只凭 coverage 数量判断没有漏指标。
- X台、XXX科、XX点和日期属于不同类型；x100%、固定阈值及普通英文 X 不属于待填指标。
- 总量/急诊、实际/拟做、人数/台次、全体/首台/连台必须区分。第一、第二、第三手术室是维度，不应改变指标含义。
- 相同手术室行出现在不同接台时点或计划章节下时，必须继承该组上下文；汇总值不能跨组复用。

## 数据与口径

- 文件名不证明数据用途。首台子集不能再次加到全明细；退单不能算实际手术，多个来源重叠要有明确手术唯一键。
- 住院号不证明患者唯一或手术唯一；无实体键只能提示补充，不按行数或拼接字段猜测台次。
- 实际手术不能仅凭唯一编号认定，还要核验已实施状态或完整实际手术事件时间。未知状态、状态和时间冲突不得静默计算。
- 读取汇总需完整上下文口径、指标、单位、日期和维度一致。同段多个数值需 slot 绑定；冲突、只有同名或旧报告数字均不能当可靠证据。
- 患者时差按明确患者键逐日去重，严格大于20/30分钟不包含等号；跨午夜必须使用完整日期时间，不从时分补日期。
- 计划量需历史快照；首台、连台、接台、比率、平均最晚时间若缺判定规则，保留具体待确认事项。
- 首台8:30/7:50、特殊科室9:00、连台50/80分钟、移植排除及退单24时边界不得擅自改写。已有这些公式不代表首台识别、关联对象和分母已经明确。

## 回填验收

逐个 slot 对照原文、单位、维度、阈值、来源与结果。所有位置都需要数值或中文缺口，未确认日期不写成昨日，缺失不写0；正文非占位部分、章节、公式及顺序保留。报告内容校验通过不代表旧 DOC 版面复刻通过。

全缺口是诊断报告，不能宣称取得真实指标值。网络、认证、结构或语义校验错误必须可见并支持有预算的重试，不能包装为业务待补充。

模型每批最多四个数字位置，输出按连接配置，应用上限为 1,000,000 tokens，实际还受模型接口能力和扣除输入预留后的剩余预算约束。核对回执中的 configuredOutputTokens 与 effectiveOutputTokens；官方 DeepSeek Flash/V4 Chat 单次最多发送 393216 tokens。截断或批次超时仅拆失败批次。语义校验只允许同批纠正一次，所有请求累计记账，禁止无限重试。UNRESOLVED 不携带可执行时差字段，已知阈值写入原因。
